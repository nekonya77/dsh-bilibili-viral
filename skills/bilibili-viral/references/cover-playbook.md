# 爆款封面手册

封面不是“配图”，是**在信息流里争取 0.5 秒点击的广告牌**。

## 一、先定一句话

写封面之前，先填：

> 让【谁】在【什么场景】下，一眼知道【能得到什么】。

例子：

- 谁：不会写代码的普通上班族
- 场景：每天要做重复表格
- 得到什么：3 分钟自动完成，不用学编程

封面大字只服务这一句，不要塞第二个卖点。

## 二、五种风格

### 1. black_yellow 黑黄大字

- 适合：工具名硬、结果数字硬、强利益点
- 结构：左侧黄色竖条 + 右上黄色斜块 + 左上角标签 + 中央 2-3 行大字
- 文字：8-14 字，动词开头，带数字/结果
- 颜色：黑 `#08080A` + 黄 `#FFD400` + 白
- 例子：`我用 AI 把 3 小时活压到 12 分钟`
- 避免：超过 3 行、每行超过 7 字、黄色面积超过 35%

### 2. split_compare 左右对比

- 适合：before/after、旧方法 vs 新工作流、工具替换
- 结构：左半灰化旧方法，右半原图，中间高亮分割线 + 三角箭头
- 文字：左右各 4-6 字标签，底部一行结论
- 颜色：灰 `#1E1E26` + 原图 + 强调 `#FF5A3C`
- 例子：`旧方法 3 小时 / AI 工作流 12 分钟`
- 避免：两边都放满截图；对比维度不统一

### 3. screenshot_callout 截图标注

- 适合：教程、实测、隐藏功能、避坑
- 结构：背景虚化，中央白色圆角卡片放截图，彩色圆圈 + 引线标关键按钮
- 文字：卡片底部一行结论，标注 4-6 字
- 颜色：深色背景 + 白卡片 + 橙 `#FF7A00`
- 例子：`就是这一步，90% 的人会漏掉`
- 避免：截图字太小、圈太多、引线交叉

### 4. gradient_tech 渐变科技

- 适合：AI Agent、编程、自动化、系统感
- 结构：深色渐变 + 网格 + 右侧竖版截图 + 左侧 2-3 行大字
- 文字：10-18 字，名词 + 动词，避免太口语
- 颜色：深蓝紫 `#0A0E1A → #1A0A24` + 青绿 `#39E6C3`
- 例子：`普通人也能搭的 AI 工作流`
- 避免：渐变过亮导致白字看不清；术语堆叠

### 5. face_bigtext 人像大字

- 适合：个人 IP、观点、经历、反常识
- 结构：左侧大字，右侧圆形人像/封面焦点，黄色描边
- 文字：8-12 字，第一人称或反常识
- 颜色：暗底 + 原图 + 黄 `#FFD400`
- 例子：`不出镜，也能做爆款`
- 避免：没有可用人像时硬用；人脸被文字遮挡

## 三、六个可复用公式

| 公式 | 结构 | 例子 |
|---|---|---|
| 数字承诺 | 超大数字 + 结果 + 小标签 | `3 小时 → 12 分钟` |
| 前后对比 | 左旧右新 + 箭头 + 结论 | `以前 3 小时 / 现在 12 分钟` |
| 红圈标注 | 截图 + 圆圈 + 一句结论 | `90% 的人漏掉这个按钮` |
| 身份反差 | 人像 + 身份 + 结果 | `不出镜，也能做爆款` |
| 清单体 | 3-5 个短句 + 拼贴 | `5 个免费工具，搭出 AI 工作流` |
| 反常识提问 | 大问号/大字 + 虚化背景 | `为什么你越努力越没流量？` |

## 四、文字规则

- 主标题 8-14 字；副标题不超过 12 字；标签不超过 6 字。
- 一行只表达一个意思；主标题最多 3 行。
- 动词优先：“压到”“省掉”“搭出”“别再”“换成”。
- 数字优先：时长、成本、数量、天数、百分比。
- 不用空词：震惊、必看、全网首发、史上最强、揭秘。
- 不用生僻缩写；AI 工具名保留英文原名。
- 标点只保留问号/箭头/斜杠，减少句号。

## 五、视觉规则

- 画布 1280x720（16:9）；安全区距边缘至少 56px。
- 主标题占画面高度 35%-55%；不要超过 60%。
- 主色不超过 3 个；强调色只用于一个焦点。
- 文字与背景对比度至少 4.5:1；深色底用白/黄，浅色底用黑。
- 加 2-4px 描边或阴影，保证手机小图可读。
- 一张图只留一个视觉焦点：大字、截图、人脸三选一为主。
- 手机缩到 320px 宽仍能读清主标题，否则重做。

## 六、生成方式

封面 spec 写在 `data/cover_specs/<week>.json`：

```json
{
  "week": "2026-W47",
  "covers": [
    {
      "id": "w01",
      "idea_id": "w01",
      "style": "black_yellow",
      "title": "3 小时活压到 12 分钟",
      "subtitle": "不用学编程",
      "badge": "AI 工具",
      "accent": "#FFD400",
      "ref_bvid": "BV1xx..."
    }
  ]
}
```

生成：

```bash
python3 -m bili_viral cover --week 2026-W47
```

输出：

```
output/covers/generated/2026-W47/w01-v1.jpg
output/covers/generated/2026-W47/w01-v2.jpg
output/covers/generated/2026-W47/index.json
```

每条生成 2 版：v1 主方案，v2 换布局/强调色/文案断行，方便 A/B。

## 七、QA 清单

- [ ] 手机尺寸 1 秒能读出利益点
- [ ] 主标题不超过 3 行，每行不超过 7 字
- [ ] 只有一个视觉焦点
- [ ] 对比度足够，描边不糊
- [ ] 没有空词/标题党/过度承诺
- [ ] 风格与标题承诺一致
- [ ] 没有遮挡人脸/关键按钮
- [ ] 2 版有明确差异，不是只换颜色

## 八、常见错误

1. 把视频标题原封不动放封面（太长）。
2. 塞 3 个卖点，等于没有卖点。
3. 截图太小，手机上看不清。
4. 黄色/红色面积过大，廉价感。
5. 字体太细，缩略图糊成一团。
6. 封面承诺和内容不一致，点击高但完播低。
7. 每期都用一个风格，用户产生视觉疲劳。

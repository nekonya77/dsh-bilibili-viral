# 爆款拆解评分表

目标不是“总结这条视频讲了什么”，而是回答三个问题：

1. **它为什么在此时被推火？**（需求/情绪/算法信号）
2. **哪一部分可以迁移到我的账号？**（选题/钩子/结构/封面）
3. **我重做时必须换掉什么？**（例子/身份/证据/场景）

## 一、先看数据，不先看内容

按这个顺序读：

| 信号 | 说明 | 高信号意味着 |
|---|---|---|
| play | 播放量 | 题材有大众需求 |
| velocity | 播放 / 发布小时数 | 正在起量，值得追 |
| like/play | 点赞率 | 内容让人认同 |
| favorite/play | 收藏率 | 工具/教程有复用价值 |
| coin/play | 投币率 | 硬核/有用，粉丝质量高 |
| share/play | 转发率 | 有社交货币或情绪 |
| reply/play | 评论率 | 有争议/有代入感 |
| danmaku/play | 弹幕率 | 有槽点/有互动节奏 |
| follower | UP 主粉丝量 | 判断“小号突破”还是“大号基本盘” |
| duration | 时长 | 判断信息密度与完播压力 |

**爆款分只做初筛，不替代判断。** 一条 5 万播放但收藏率 8% 的教程，可能比 50 万播放的泛娱乐更适合你的账号。

## 二、六维拆解

### 1. 选题：谁，在什么场景，想解决什么

- 目标人群是否具体？（“普通人”太宽，“不会写代码但想做自动化的人”才具体）
- 需求是**省时间、赚钱、省钱、避坑、身份认同**中的哪一种？
- 为什么是现在？（新工具发布、版本更新、平台政策、季节节点）
- 选题是“信息差”还是“执行差”？信息差会过期，执行差可长期做。

### 2. 标题： curiosity gap + 具体性 + 身份

逐字拆：

- 有没有数字/时间/成本/结果？
- 有没有一个“反常识”或“未完成”的信息缺口？
- 有没有点名人群或场景？
- 有没有过度承诺/标题党风险？

好标题通常只做对 1-2 件事，不是把所有元素堆满。

### 3. 前 3 秒：钩子

逐字记录口播/画面：

- 第一帧给的是**结果**、**冲突**、**问题**还是**身份**？
- 有没有“与我有关”的信号？
- 有没有视觉证据（屏幕、数字、对比）？
- 如果 3 秒内没出现利益点，完播率通常会被腰斩。

### 4. 结构：信息释放顺序

用时间轴写：

```
0:00-0:03 钩子
0:03-0:20 背景/痛点
0:20-1:30 演示/论证 1
1:30-2:30 演示/论证 2
2:30-3:30 转折/限制/反例
3:30-4:00 总结/行动
```

判断：

- 每 20-30 秒有没有新的信息点/画面变化？
- 是先给结果再解释，还是先铺垫再给结果？
- 有没有“只有作者能拍”的证据（实测、翻车、后台数据、真实案例）？
- 有没有明显的节奏塌陷（连续口播超过 40 秒无画面变化）？

### 5. 封面：1 秒测试

把封面缩小到手机尺寸，问：

- 1 秒内能读出**利益点**吗？
- 视觉焦点是一个还是三个？
- 大字和背景的对比够不够？
- 有没有“点击理由”（数字/对比/红圈/人脸/反常）？
- 风格是否和标题承诺一致？

### 6. 观众为什么买单

从评论/弹幕/描述找证据，归到五类欲望：

- **赚钱**：接单、副业、涨粉、变现
- **省时间**：自动化、模板、工作流
- **省成本**：免费替代、0 成本、低成本
- **避坑/安全**：别踩雷、别被封、别被骗
- **身份/归属**：普通人也能、不上班、第一次、同行共鸣

不要凭空猜“用户喜欢”；至少找到 1 条评论/弹幕/数据作为证据。

## 三、评分（0-10）

对每条视频打四个分：

| 维度 | 问题 | 低分 | 高分 |
|---|---|---|---|
| topic | 需求是否具体、是否现在 | 泛泛而谈 | 具体人群 + 明确结果 + 时效 |
| cover | 1 秒能否读懂利益点 | 信息堆砌 | 单一焦点 + 强对比 + 点击理由 |
| script | 钩子/结构/证据是否成立 | 铺垫长、无证据 | 前 3 秒给结果、每段有证据 |
| production | 是否可被低成本复刻 | 依赖大量素材/出镜 | 录屏 + 口播即可 |

**本周选题优先级**：

```
priority = 0.35 * topic + 0.25 * cover + 0.25 * script + 0.15 * production
```

优先做 `priority >= 7.5` 且自己能在一周内拍完的题。

## 四、差异化重做

不要“换个说法重拍”。从下面选一个维度换：

1. **换人群**：从“AI 工具”换到“不会写代码的行政/HR/老师”。
2. **换场景**：从“通用工作流”换到“写周报/做表格/剪口播”。
3. **换证据**：从“功能介绍”换到“我实测 7 天/花了 0 元/翻了 2 次车”。
4. **换反方**：从“教你用”换到“什么情况下别用”。
5. **换成本**：从“最强工具”换到“免费替代/最低成本方案”。
6. **换形式**：从“教程”换到“挑战/复盘/对比/避坑”。

重做时必须至少满足两条：

- 目标人群或场景不同；
- 证据/案例不同；
- 结构或封面钩子不同；
- 有新的时效信息（版本/价格/政策）。

## 五、风险检查

- 事实：工具版本、价格、功能、数据是否可核实？
- 版权：是否使用了他人视频/音乐/图片？只做短引用并标注来源。
- 合规：是否暗示保证收益、诱导付费、伪造经历？
- 隐私：截图是否含个人信息/公司数据？
- 平台：是否引导站外交易/下载？是否涉及敏感行业？

## 六、输出检查清单

每条视频的分析至少包含：

- [ ] 一句话选题（不是标题复述）
- [ ] 3 个爆点（数据/情绪/结构）
- [ ] 前 3 秒逐字钩子
- [ ] 时间轴结构
- [ ] 封面风格 + 大字 + 颜色 + 为什么
- [ ] 我能怎么差异化（具体到人群/场景/证据）
- [ ] 四维评分 + 风险
- [ ] 至少 1 条评论/弹幕/描述证据（有字幕时引用字幕）
